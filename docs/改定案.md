# 改定案 ── 入口、可読性、第三部、短縮ルート

2026年9月29日。事前調査（worktree「全面改定の事前調査」）と、そのレビューを受けて書いた。実装はこの文書を基準にし、各段階の終わりに Codex がこの文書を参照してレビューする。

## 1. 目的と、読者の軸

目的は一つ。**問いと答え合わせ、五地域の比較、実物と博物館の接続という、この読み物の価値を、初めて来た人が早く体験できるようにする。** いまの骨格と文体は壊さない。

読者は年齢で分けない。事前調査は「大人には成立し、中高生には成立しにくい」と書いたが、この調査方法では確かめられない。代わりに次の三つの軸を置く。

| 軸 | 分かれ方 |
|---|---|
| 予備知識 | 古代史の予備知識があるか、ないか |
| 興味の対象 | 人物、神話、文字、建築、地図、気候のどれに惹かれるか |
| 使い方 | 博物館の予習か、短時間の拾い読みか、通読か |

「中高生には大きな写真や動きが必要」は仮説として扱い、動きの追加は提案から外す。読者が実際にどこで興味を持ち、どこで止まるかは未観察なので、実装後に人で確かめる（§7）。

### A. 冒頭の体験

- 写真は `img/05-egyptian-relief-head.jpg`。作成者が館で撮影した男性頭部の浮彫で、SNS共有用の画像（og-relief.png）と同じ。共有画像から来た人が同じ顔に迎えられる。
- 問いは第三部エジプトの問いを、写真で確かめられる形にする。「顔は横向きなのに、目だけは正面を向いている。この描き方の約束は、王朝が代わっても、細部を変えながらおよそ三千年受け継がれた。なぜか。」本文の留保「細部を変えながら」を落とさない。
- 導線は二つ。「答えは、第三部 エジプトの節に」（#p3-egy）と「答えだけ見る」（#p3-egy-a）。
- 置き場所は h1 の直後。lede（「六つの見方」の一文）はその後に回す。実物と問いを先に、射程の説明をあとに。PC幅では写真と問いを横に並べる。スマホ幅では冒頭の余白を64pxに詰め、写真を16:10で画面の端まで広げ（`margin-left:calc(50% - 50vw)` で中央基準）、その下に問い。「文明のすべては…」の主張は残す。
- キャプションは「男性の頭部の浮彫断片。石灰岩に彩色。古代オリエント博物館の展示より、2026年9月3日撮影」。
- **判定:** PC 1280×800 とスマホ 390×780 の最初の一画面に、写真、問い、答えへの導線が入る。写真は遅延読み込みにしない。

### E. 第三部の役割分離（段階2）

- 各地域の節を「性格の説明 → 地図 → 実物 → 答え」の本線と、「年代で追う」参照に分ける。参照は「参照 ── 年代で追う」の折りたたみへ。折りたたみの外の文は、一覧を開かなくても読めるように、年代や時代名を直接言う。
- 表を指す文（「上の表を縦に眺めると」など）は、折りたたみの位置に合わせて書き換える。答えの文は変えない。
- メソポタミアの南北表は折りたたむ。段階1のレビューで、往復のリズムは直後の「統一政権と分立の期間」の図が直接伝えている、との判断材料を得た。冒頭の文は「南と北の歴史を縦に眺めると」に書き換え、閉じた表に依存しない。
- アナトリアの節は年代の一覧で始まっていたので、性格を二文で述べる段落を先頭に足す。
- **判定:** 第三部の本線の表示時間が21分から15分前後へ。五つの答えの文が変わっていない。
- **結果（段階2）:** 本線21分から16分へ（補足込みは29分のまま。表と一覧は折りたたみに残る）。答えの文は不変。

### F. 短縮ルート（段階3）

- 「問いと答えで読む」を冒頭と各部の扉から選べる。表示するのは、各部の扉と問い、部ごとに1〜2点の写真か図、答え合わせ、地域の答え、博物館で。
- 実装は `body.short` と `data-short` 属性と CSS。所要時間は本線とは別に算定して表示する。選択は保存しない。
- 読了の記録は変えない。答え合わせが画面に入ると読了扱いになる仕様は、短縮ルートでも同じであることを、末尾（footer）の作成記録に一文で書く。短縮ルートの表示中は、読書位置（続きから読む）を保存しない。
- 表示する図版（data-short、17要素）: 第一部は13万年の気温の図（1）。第二部は「五つの世界」の地図（1）。第三部は礼拝者像、覇権のリズムの図、歩むライオン、男性頭部の浮彫、孔雀のモザイク、アナトリアとイランの期間の図（7）。第四部は「三通りの形」の図とウルのジッグラトの写真（2）。第五部は乗り物と乗客の図と粘土板の写真（2）。第六部は二本の帯とその一文（3）。第七部は「村は山麓に、都市は平野に」の地図（1）。五つのキャラクターのカードと第七部の高さくらべは、時間を15分に収めるために外した。
- 博物館の節は会場用の一覧なので、短縮ルートでもそのまま表示するが、所要時間の算定には含めない（含めると約16〜17分）。算定の対象は七部の扉と問い、印をつけた図版、答え合わせと地域の答え。
- 切り替えは冒頭のボタンと、各部の扉の所要時間の札の隣のボタン。表示中は画面下の帯から「全部を読む」で戻る。
- 隠れている先へ飛ぶ操作（本文中のリンク、上部ナビ、URL の #、図版をひとつ引く、館で探す実物の一覧）は、全部の表示に戻してから飛ぶ。
- **判定:** 短縮ルートの所要時間が15分以内。すべての答え合わせに、写真か図が1点はついている。
- **結果（段階3）:** 表示は「問いと答えで読む ── 約15分」（本線と同じ450字／分で算定）。七つの答え合わせすべてに図版が1点以上ある。

### G. フォント（段階3）

- 案: 明朝を400と600の2ウェイトに絞る（700の6要素は600へ）。ゴシックは400、500、700のまま。
- **判定:** 変更前後の転送量を同じ方法（DevTools の Network で Font の合計）で計測して、この文書に記録する。扉と本文の見た目を比べて差を確認する。
- **結果（段階3）:** 同じ方法（ヘッドレス Chrome、キャッシュ無効、本文全体を読み込んだ状態）で計測。

| | ファイル数 | 合計 | 明朝 | ゴシック | 楔形文字 |
|---|---|---|---|---|---|
| 変更前（明朝4ウェイト） | 259 | 3,851,041 B | 1,932,758 B | 1,608,931 B | 309,352 B |
| 変更後（明朝2ウェイト） | 258 | 3,817,099 B | 1,898,785 B | 1,608,962 B | 309,352 B |

  減ったのは34KB（0.9%）だけだった。ブラウザは使っているウェイトのぶんしか取りに行かないので、要求から外しても転送量はほとんど変わらない。Google Fonts の CSS は209KBから148KBに減った。見た目の差は、明朝700を使っていた6要素が600になるだけで、確認できる差はない。

## 6. レビューの観点（Codex 用）

1. 文章方針に沿っているか。短い文、初出の注釈、脱線は折りたたみ、著者の断言調は残す。
2. 特別展の扱い。既存の言及（年表の注記、比較表の★の注記、第七部の導入、「この資料について」）は残す。新しく書く文では催事の案内（会期、料金、「会場で」）を書かず、言及するなら過去形。
3. 新しく書いた文の事実。年代、名称、「三千年」「前3100」などの数字。
4. 既存の仕掛けが壊れていないか。読了の記録、続きから読む（段階1の手直しから、部の先頭からの相対位置で戻る。相対位置のない古い記録は部の先頭へ）、まだ読んでいない部へ、図版をひとつ引く、地図のつまみと再生、五つの世界の玄関、博物館の見つけた印、URL の # での着地。
5. 可読性の数値。コントラスト、所要時間。
6. 省略で誤解を生む表現がないか（「全体を」の例）。
7. この文書の各項目の「判定」を満たしているか。満たしていなければ、どの判定か。

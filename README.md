# 古代オリエントを立体で読む

メソポタミア・エジプト・アナトリア・地中海東岸・イラン高原 ── 五つの地域の一万年を、時間・空間・文明・神・言語・建築の順にたどる読み物です。

もともとは古代オリエント博物館 夏の特別展「古代オリエントのたてものとまちづくり ── 模型で探検！」（2026年7月4日〜9月6日）の予習用としてつくったものですが、会期にかかわらず、博物館の展示を見る前後の下地として読めるように書いています。

## 構成

| 第二部 | 空間 ── 五つの世界 |
| 第三部 | 文明 ── 五地域の性格と、四つの時代の地図 |
| 第四部 | 神 ── 神と人の距離のつくり方 |
| 第五部 | 言語 ── 文字は乗り物、言語は乗客 |
| 第六部 | 統合年表 ── 全36項目 |
| 第七部 | 建築 ── たてものと、まちづくり |

## 読み進めるための仕掛け

- 各部は「この部の問い」で始まり、末尾の「答え合わせ」で答える。答え合わせから次の部の問いへ続けて飛べる
- 目次に、部ごとの所要時間（本線／補足まで）と、読了・途中・未読の印が出る
- 「続きから読む」で前回の場所へ戻れる。読んだ部、開いた図版、会場で見つけた実物の記録は、端末のブラウザにだけ保存される（サーバーには何も送らない）
- 「図版をひとつ引く」で、まだ開いていない地図や写真を一枚引いて拡大表示する
- 末尾の「博物館で」は会場用のページ。模型の前で使う四つの問い、本文に出てくる館の展示品の一覧（見つけた印をつけられる）、特別展で模型になった建築10件への索引
- 図版は画面に入ったときに線が描かれ、カードは静かに現れる（OSの「視差効果を減らす」設定では動かない）
- 各部に「ひと話」を一つ置き、折りたたみに入っていた話（テル、メケトラー墓の建築模型、ウガリトの粘土板、高さくらべなど）を本線で読めるようにした
- 第三部の「四つの時代」は、つまみで前3000年から紀元前後まで動かして眺められる（4コマ図はそのまま下に残してある）
- 本線の写真は段組みより広く表示する（スマートフォンでは画面の端から端まで）

## 特徴

- HTMLは一枚（約0.55MB）。地図41点のSVGは埋め込み、写真14点は `img/` から配信（検索エンジンの速度評価と初回表示のため、2026年9月4日に埋め込みから分離）
- 地図41点はすべて自作のSVG、写真14点（パブリックドメイン等の素材8点と、館内で撮影した6点）を埋め込み
- 地図・写真はタップで拡大表示
- 第二部の「五つの世界の玄関」で地域を選ぶと、その地域の話が各部のどこにあるか一覧になり、そこへ飛べる
- スマートフォンでの閲覧に最適化（博物館で読み返せる密度）

## 公開方法（Vercel）

ビルド不要の静的サイトです。設定は要りません。

1. このリポジトリをGitHubにpush
2. Vercelで **Add New → Project** からこのリポジトリをインポート
3. Framework Preset は **Other**、Build Command と Output Directory は空のままでDeploy

`index.html` がそのままトップページとして配信されます。以降はGitHubにpushするたび自動で再デプロイされます。

## 検索エンジンと計測

- `robots.txt`・`sitemap.xml`（写真14点の一覧つき）・`manifest.webmanifest`・`og.png`（SNS共有用の画像）をリポジトリ直下に置いてある。`index.html` の `<head>` に canonical、OGP、構造化データ（JSON-LD の `Article`。`about` に古代オリエント博物館）がある
- `og.png` は `python3 tools/make-og.py` で作り直せる（Pillow と macOS のヒラギノ明朝が必要）。題や副題を変えたら実行する
- Google Search Console: 「URLプレフィックス」で公開URLを登録し、所有権確認の「HTMLタグ」のトークンを `<head>` のコメントにある `google-site-verification` に入れて公開する。その後 `sitemap.xml` を送信し、URL検査から「インデックス登録をリクエスト」する
- Vercel Web Analytics: ダッシュボードの Analytics で Enable にしてから、`</body>` 直前の計測スクリプトを有効にする（Hobby プランは月5万イベントまで無料、超過は収集が止まるだけ）
